# 部署会意网站

## GitHub 与托管平台分别做什么

仓库保存网站源码和版本。网站使用服务端接口保护模型密钥，需要运行 Node.js 的平台；不适合只部署静态文件的 GitHub Pages。本指南使用 Vercel，也提供 Docker 方式。

## Vercel

1. 在 Vercel 创建项目，选择 **Import Git Repository**，连接 GitHub 并选择 `zxcv12390/AIliao`。
2. 框架保留 **Next.js**，根目录为仓库根目录。使用 Node.js 22 或更高版本；安装命令 `npm ci`，构建命令 `npm run build`，输出目录使用框架默认设置。
3. 在环境变量中添加下表配置。密钥与口令通过平台的安全输入框设置，不发在聊天、Issue 或仓库里。
4. 部署。第一次打开时先试预设示例，在「我的表达」中输入访问口令，再尝试自己的内容。
5. 修改环境变量后重新部署，让新进程读取新配置。

| 变量 | 是否需要 | 用途 |
| --- | --- | --- |
| `AILIAO_API_KEY` | 真实 AI 功能必需 | OpenAI 或实际兼容 Responses API 的模型 Key；服务端也兼容 `OPENAI_API_KEY` |
| `APP_ACCESS_TOKEN` | 生产环境默认必需 | 站点访问口令；使用者在「我的表达」中输入，不能代替模型 Key |
| `AI_MODEL` | 可选 | 默认 `gpt-4.1-mini`，需支持图片与结构化输出 |
| `OPENAI_BASE_URL` | 可选 | 默认 `https://api.openai.com/v1`；不包含 `/responses` 后缀 |
| `ALLOW_PUBLIC_ACCESS` | 可选 | 默认不启用；设为 `true` 可允许不设口令的公开调用，费用由部署者承担 |

不要给这些变量加 `NEXT_PUBLIC_` 前缀。该前缀会用于浏览器可见配置。

网页搜索使用 `web_search` 工具，需模型、API 账户和服务端网络支持；是否收费及价格以供应商当前说明为准。搜索能力与普通 ChatGPT 订阅不是同一种 API 额度。

## Docker

```bash
docker build -t ailiao .
# 将实际变量写入本地 .env.local，不提交该文件。
docker run --rm --env-file .env.local -p 3000:3000 ailiao
```

公开服务应由支持 TLS 的反向代理或托管平台提供 HTTPS。浏览器的屏幕捕获和剪贴板能力受安全上下文、系统和权限限制。

Dockerfile 使用多阶段构建与非 root 用户运行。此仓库提供配置；当前交付未进行 Docker 构建验证，不应把 Next.js 构建通过当成镜像已验证。

## 其他 Node.js 平台

安装 `npm ci`，构建 `npm run build`，启动 `npm run start`，通过环境变量 `PORT` 设置平台要求的端口，`HOSTNAME=0.0.0.0` 设置监听地址。构建后的脚本会准备好 standalone 服务需要的静态资源。平台需要允许访问配置的模型 HTTPS 地址。启动时注入环境变量，勿把实际 Key 烘焙进镜像。

## 部署后最小验收

1. **无密钥模式**：页面可打开，三个示例可切换，自定义请求会提示未连接模型。
2. **口令**：错误或缺少口令不产生模型调用；正确口令可使用。刷新后网页内口令清空。
3. **文字**：贴一段不含隐私的对话，生成的三条回复对应真实场景，修改语气后重新生成。
4. **截图**：上传清晰聊天图，确认谁说了什么；再用遮挡的图，确认模型会承认看不清。模型判断可能出错。
5. **屏幕截取**：浏览器授权后只获取一帧，页面出现截图，共享提示停止；取消授权应有友好提示。
6. **联网**：填写抽象公开主题，确认结果出现可访问且相关的来源。不应凭空显示来源，无法查证时不展示伪成功结果。
7. **手机**：上传相册截图，页面无横向滚动，收藏、复制、偏好弹窗可用。部分手机浏览器不支持屏幕捕获，可使用相册上传。

请分别记录真实模型名、执行日期和通过项。自动化测试使用模拟模型，不能代替以上实测。

## 常见问题

- **只有示例，生成提示未连接**：检查运行环境的 Key 名称是否正确，环境变量改动后是否已重启或重新部署。
- **提示模型鉴权失败**：检查模型供应商的 API 访问权限与 Key 状态，不能通过 ChatGPT 登录状态推断 API 权限。
- **提示部署未开放**：生产环境需要 `APP_ACCESS_TOKEN`，或明确设置 `ALLOW_PUBLIC_ACCESS=true`。
- **口令错误**：在「我的表达」重新输入站点口令，不是 API Key。口令不要发给不打算授权的人。
- **接口报不支持**：仅有 `/chat/completions` 不够；需要支持 `/responses`、图像输入和严格 JSON Schema。联网还要支持 `web_search`。
- **搜索失败**：先关闭联网验证普通分析，再检查模型工具能力、账户权限、网络和检索主题。网站不会悄悄把失败搜索换成编造结果。
- **额度不足 / 429**：检查供应商余额、配额及每分钟请求限制，稍后再试。
- **超时**：每个模型请求有 45 秒超时，带搜索时最多有两次顺序请求。平台也有自己的运行时长限制。
- **图太大**：页面在本地缩放并压缩，单图发送最多约 1 MB；总请求限制 4.4 MB。裁剪到需要的聊天区域可改善识别。
- **无法截屏或复制**：确认是 HTTPS 或 localhost，并检查浏览器授权；用系统截图上传、手动选中文字作为替代。
- **公网多人使用**：当前访问口令是共享口令，单实例限流不是计费系统。进一步上线运营前应增加账户、共享限流、供应商额度控制及适用的隐私说明。
