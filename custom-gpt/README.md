# 前期自定义 GPT 配置（可选资料）

网站已经独立运行，无需创建自定义 GPT。这些文件保留前期沟通设计与知识资料，也可用于手动创建 GPT。

如需使用旧方案：在 ChatGPT 的 GPT 编辑器中，将 [INSTRUCTIONS.md](INSTRUCTIONS.md) 全文粘贴到指令，上传 `knowledge` 下三份 Markdown，启用账号实际可用的图片理解与网页搜索能力。`builder.json` 只是配置记录，不是官方导入格式。

截图要在聊天框主动上传，不能后台读取桌面。实际能力以账号与模型为准，按[旧方案验收清单](../docs/验收清单.md)测试后再分享。

目前推荐直接使用仓库根目录的 Next.js 网站。
